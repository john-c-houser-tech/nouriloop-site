Compromise Checker

A tool that checks Linux servers for signs of a break-in. It logs in over SSH, runs a small read-only collector on the server's own Python, brings the evidence back and analyzes it on your own machine. The tool writes nothing to the server. Open source under AGPL, and built for small organizations that can't afford commercial security products and would rather not use a command line. The first pre-release, 0.1.0, is out: how to install it.

  • What it does: checks Red Hat Enterprise Linux 9 and later (tested on Rocky Linux and AlmaLinux) and Ubuntu 22.04 and later; compares each server with its own baseline; links findings that tell an attack's story; and estimates each server's chance of a break-in, in plain words, with the evidence behind every finding and what the check couldn't see. Signed threat packs teach it about new attacks without a new release of the tool. An optional AI advisor explains a result, proposes whitelist rules, suggests better coverage and advises on remediation. It only advises: nothing it says runs.
  • What it's built on: Python, AsyncSSH, and Django for the web interface; evidence encrypted with age. The advisor works with Anthropic's models or a local model through Ollama or the like, with server names, user names, addresses and key fingerprints replaced by default before anything is sent.
  • How it's tested: on throwaway servers running seven Linux images, auditd recorded every write by the tool's session, and the collector made none. Thirty scripted break-ins on Ubuntu and Rocky Linux each produced its finding, and fresh servers score Low.
  • How it was built: the same way as NouriLoop, with AI coding agents and John planning, directing and reviewing every step. More than 120 pull requests in its first ten days, each one reviewed before it was merged, and 60 test files that run on every change.

Screenshots are from a demo fleet of throwaway servers, attacked on purpose. Real results; addresses replaced.

NouriLoop

A nutrition-tracking web app with AI built in from the ground up. It's live at app.nouriloop.com, open source under AGPL, and anyone can run their own copy with Docker in about an hour.

  • What it does: logs meals, recipes and supplement labels from a photo; shows how each meal moved your glucose, using a continuous glucose monitor; turns a goal described in plain words into a measurable one, with check-ins in the app, by email or by text; works in six languages.
  • What it's built on: Symfony and PHP, MariaDB, Stripe and Twilio. The AI provider can be swapped between Anthropic, OpenRouter and Ollama, and every AI call is metered.
  • How it was built: mostly with AI coding agents, with John planning, directing and reviewing every step. Since June 2026 that's more than 250 pull requests, each one reviewed before it was merged, and more than 180 test files that run on every change.
  • How it runs: in production, operated by one person, with uptime monitoring, encrypted nightly backups kept offsite, automatic security updates, automatic dependency updates and a weekly vulnerability audit.

Library software

Open-source tools for libraries that run the SirsiDynix Symphony library system. Both are released under the GPL and are in production at Oregon library systems.

  • libilsws: a PHP package for Symphony's Web Services API. Other library tools are built on it.
  • ReLibConnectEd: an automated pipeline that loads student records from school districts into the library system, so students get library accounts through their schools. It validates the data, standardizes addresses to USPS format, skips records that haven't changed, and emails each district a report after every run.

A Python rewrite of ReLibConnectEd is in user acceptance testing and will be released as open source when it's finished.
